# 🎱 ΜΠΙΛΙΑΡΔΟ PRO — Ο Δάσκαλος

Ολοκληρωμένος **offline προπονητής μπιλιάρδου** για όλα τα είδη — από αρχάριος σε επαγγελματία.

## Τι περιλαμβάνει
- **Μαθήματα**: στάση, λαβή, γέφυρα, χτύπημα, στόχευση (ghost ball / fractional), έλεγχος λευκής, φάλτσα, θέση, νοητικό παιχνίδι
- **Προπονητής Στόχευσης**: διαδραστικό τραπέζι με ζωντανό υπολογισμό γωνίας κοψίματος, ghost ball & εφαπτομένης
- **Διαδραστικό Μπιλιάρδο vs AI** με φυσική, **2D & 3D** προβολή και **φάλτσο** (follow/draw/πλάγιο):
  - 9-Ball, 8-Ball (ρίγες/μονόχρωμες), Snooker, Καραμπόλα 3 μπάντες, Ελεύθερη εξάσκηση
- **Ασκήσεις** με καταγραφή σκορ, **Puzzles τακτικής**, **Roadmap** προόδου
- **Συστήματα διαμαντιών**, γλωσσάρι, μετρονόμος ρυθμού
- **Επιλογή χρωμάτων** (τσόχα + όλο το εργαλείο)

## Χρήση
Είναι **PWA**: άνοιξε το live link και πάτα «Προσθήκη στην αρχική οθόνη» για να το εγκαταστήσεις σε κινητό/tablet/PC. Λειτουργεί και **offline** μετά την πρώτη φόρτωση.

Όλη η πρόοδος αποθηκεύεται τοπικά στη συσκευή (localStorage).
